# Job Finder AI

AI-assisted job search for remote technology roles and Pakistan listings, with resume parsing, personalized matching, application tools, and a personal job tracker.

[Live application](https://ai-jobfinder.vercel.app/) · [Backend readiness](https://job-finder-ai-backend.onrender.com/api/ready) · [Issues](https://github.com/KhuzaimaHassan/job-finder-ai/issues)
